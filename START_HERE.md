# Start here

[README.md](README.md) is the current guide for cloning, setup, live use, encounters, and the project results.

- Run `sh SETUP_MAC.command` on Mac, or `SETUP_WINDOWS.cmd` on Windows.
- Launch the dashboard and connect an existing R19 Nicla. Use [DEPLOYMENT.md](DEPLOYMENT.md) for flashing or recovery.
- Use [TRAINING.md](TRAINING.md) and [DATA.md](DATA.md) for model research.
- Use [WINDOWS_VIDEO_POWER_BENCH.md](WINDOWS_VIDEO_POWER_BENCH.md) for metered experiments.
- Read [engineering handoff](docs/development/AGENT_HANDOFF.md) before automated device work.

Current engineering release is R19 with the November 16 gallery and import changes. Automatic known-person acceptance remains disabled. The physical battery rehearsal remains pending. Source and deployment assets are now maintained in this Git repository.
